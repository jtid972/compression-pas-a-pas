# Journal des versions

Les versions de maintenance mensuelles (1.0.1, 1.0.2…) sont décrites dans les *Releases* GitHub.

## 1.0.0 — 2026-11-08

Première version publique.

- Vidéos : Full HD / HD Ready, trois niveaux de qualité, son réglable (normal, réduit, mono, sans son), MP3 séparé en option ; format d'origine conservé.
- Images : Full HD / HD Ready, même format (JPEG, PNG, WEBP, HEIC, AVIF, TIFF, BMP, GIF), conversion JPEG et PNG 256 couleurs en option.
- Documents Word, PowerPoint, Excel, LibreOffice et OnlyOffice : recompression des images intégrées, document modifiable au même format.
- PDF : compression des images, réduction des polices, structure PDF 1.5 ; version Word et/ou PowerPoint modifiable, avec reconnaissance de texte (OCR) pour les PDF scannés.
- Estimation du gain avant lancement ; traitement déconseillé sous 10 % ; original conservé si aucun gain.
- Interface adaptée au téléphone, mode sombre, application installable (PWA) et partage de fichiers depuis Android.
- Licence AGPL-3.0-or-later, licence commerciale possible ; lien « Code source » dans la page.
- CI Linux / macOS / Windows, contrôle Trivy bloquant avant publication, analyse hebdomadaire, version mensuelle automatique, Dependabot avec fusion automatique des mises à jour testées.
